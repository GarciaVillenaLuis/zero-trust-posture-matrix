# Zero Trust Posture Matrix 🌐

Continuous verification engine and maturity assessment framework aligned with **NIST SP 800-207** and **CISA Zero Trust Maturity Model (ZTMM)**.

## Pillars Assessed
1. **Identity**: Phishing-resistant MFA, conditional access policies, continuous adaptive risk evaluation.
2. **Device**: Endpoint compliance posture, EDR telemetry, hardware-bound tokens.
3. **Network**: Micro-segmentation, encrypted overlay transit, zero implicit perimeter trust.
4. **Application**: Workload identity federation, TLS 1.3 mutual auth, API authorization guardrails.
5. **Data**: KMS envelope encryption, DLP inspection, automated data classification labeling.

Telemetry index published in [`matrix/zero_trust_maturity.json`](./matrix/zero_trust_maturity.json).
